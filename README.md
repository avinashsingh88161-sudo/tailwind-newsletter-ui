# 📩 Tailwind CSS Newsletter UI

A simple and clean **Newsletter Subscription UI** built using **HTML5** and **Tailwind CSS**.

This project was created as part of my learning journey with Tailwind CSS. I built this UI to practice Tailwind's utility-first approach and understand how different utility classes can be combined to create a clean interface.

## 🚀 Features

- Clean and simple newsletter UI
- Responsive layout
- Gradient header section
- Email input field
- Subscribe button
- Rounded UI components
- Tailwind CSS utility classes
- Simple and beginner-friendly structure

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- VS Code

## 📚 What I Practiced

While building this project, I practiced:

- Flexbox
- Spacing and sizing
- Typography
- Colors
- Gradients
- Borders
- Border radius
- Form styling
- Tailwind CSS utility classes
